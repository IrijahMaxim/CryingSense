# Performance Reports

Contains all model performance reports, training outputs, and experiment results.

## Structure

### `training_report/`
- `training_curves.png` - Training/validation loss and accuracy plots
- `training_history.json` - Epoch-by-epoch metrics

Generated by: `python model/training/train.py`

### `evaluation_report/`
- `confusion_matrix.png` - Visual confusion matrix
- `classification_report.txt` - Precision, recall, F1-score per class
- `evaluation_results.json` - Complete evaluation metrics

Generated by: `python model/training/evaluate.py`

### `validation_report/`
- `validation_classification_report.txt` - Validation metrics

Generated by: `python model/training/validate.py`

### `logs/`
Runtime logs and debugging information

## Model Weights
Model weights (`cryingsense_cnn_best.pth`) are stored in `model/saved_models/`
